# fair.md v0.3.0 — evidence before assertion

v0.3.0 is a major integrity and FAIR-logic revision of the fair.md convention:
a portable `FAIR.md` front door that connects human-readable declarations,
machine-validation, implementation choices, and evidence-backed assessment.

## Highlights

- Evidence objects replace unsupported scalar FAIR claims.
- RDA FAIR Data Maturity Model metric identifiers can be attached to results.
- Structured vocabulary, profile, resource, license, and conformance
  declarations make implementation choices explicit.
- FAIR and openness are assessed separately using an Open Definition posture.
- The `fair-documented/` source pack records authoritative sources, standards
  mappings, evidence and checksum policies, an optional ISA profile, and
  RO-Crate metadata.
- The validator checks JSON Schema conformance plus cross-field integrity,
  exact-case local references, ORCID checksums, DOI syntax, and other semantic
  rules.

## Scope and limitations

fair.md v0.3.0 is a proposed convention, not a certification scheme or an
endorsed community standard. A conforming file demonstrates structural
validity; FAIR assessment results still require target-specific evidence and
independent scrutiny. The release does not claim endorsement by GO FAIR,
FAIRsharing, RDA, RO-Crate, ISA Tools, or any other community.
