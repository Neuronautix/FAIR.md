# fair.md v0.3.1 — community-readiness release

v0.3.1 packages the governance, citation, examples, and review-readiness work
accepted through [pull request #3](https://github.com/Neuronautix/FAIR.md/pull/3).
It is a backward-compatible patch release of the v0.3 proposed convention.

## Highlights

- The canonical `FAIR.md` records the stable Zenodo concept DOI separately from
  version-specific citation identifiers.
- Contribution guidance, change-approval governance, a Code of Conduct, and a
  formal community-review process are now part of the repository.
- Complete v0.3 packages demonstrate a generic dataset and an illustrative
  ISA-Tab Investigation–Study–Assay project.
- Default validation includes nested `examples/**/FAIR.md` packages and their
  root-relative resources and evidence.
- Validator tests use the same recursive example discovery behavior.
- The ISA example consistently declares ENVO for environmental material and UO
  for degree Celsius.

## Scope and limitations

fair.md remains a proposed convention, not a certification scheme or an
endorsed community standard. Structural conformance does not certify that a
digital object is FAIR. Maintainer-authored assessment results require
target-specific evidence and independent scrutiny.

The ISA example is marked `aligned`, not `adopted`; it does not claim an
external ISA validator result or ISA community endorsement.
